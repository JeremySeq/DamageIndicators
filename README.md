# JeremySeq's Damage Indicators

A lightweight combat HUD mod for directional damage indicators, floating damage numbers, and mob health bars.

[![available on CurseForge](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3.2.0/assets/cozy/available/curseforge_vector.svg)
](https://www.curseforge.com/minecraft/mc-mods/jeremyseq-damage-indicator)[![available on Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3.2.0/assets/cozy/available/modrinth_vector.svg)
](https://modrinth.com/mod/jeremyseqs-damage-indicator)
## Features
- **Directional Damage Indicator**: an arrow pointing in the direction of any incoming damage
- **Damage Text**: text showing the amount of damage dealt to other mobs
- **Health Bars**: a text health bar for other mobs
- **Blood Overlay** (disabled by default): an overlay of red outlining your screen when you take damage

## Config
There is one config file called `jeremyseqsdamageindicators.json`.

You can...
- enable/disable each feature
- change the color, placement, timing, and texture of the directional indicator
- make the health bar only show for targeted mobs
